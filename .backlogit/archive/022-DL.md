# Direct SharePoint/OneDrive stream.aspx audio stream, transcript tab activation, and Copilot AI summary capture (033-S)

## Problem Frame

<!-- BEGIN:problem-frame -->
Direct SharePoint/OneDrive stream.aspx recording URLs (https://<tenant>.sharepoint.com/personal/<user>/_layouts/15/stream.aspx?id=/personal/<user>/Documents/Recordings/<file>.mp4) lack 'teams' or 'meetingrecap' substrings and exhibit four coupled failures: (1) stream.aspx pre-buffers fMP4 segments in a Web Worker during Join before CaptureAudio hooks install, and track=video (wsd=96000) overwrites track=audio (wsd=96256) in inspectTranscodeRequest; (2) stream.aspx opens the Copilot sidebar by default so .ms-List is unmounted until the Transcript tab button is clicked; (3) stream.aspx uses the Copilot 'Recap the meeting' prompt (.fai-CopilotMessage) rather than Teams Notes -> AINotes -> Copy all; and (4) stream.aspx carries the recording path in the id query parameter rather than fileUrl.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
- Option A (Recommended): In-page PerformanceResourceTiming + g_fileInfo.EncKey WebCrypto seeding with track!==video wsd guard, idempotent Transcript tab activation, Copilot .fai-CopilotMessage extraction with 60-attempt (30s) polling, and id-parameter RecordingName identity matching across U1..U4 (033.001-T..033.004-T)\n- Option B: Force navigation from stream.aspx to teams.microsoft.com/l/meetingrecap (rejected: direct SharePoint/OneDrive recordings often have no Teams threadId or meetingrecap route)\n- Option C: Reload the stream.aspx page inside CaptureAudio to re-trigger MediaSource initialization after hooks install (rejected: adds full SharePoint reload latency, risks auth/throttling, and still fails when segments are fetched inside a Web Worker)
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option A: Decompose covering feature 033-F into four width-isolated tasks (033.001-T code, 033.002-T browser tests, 033.003-T CLI integration tests, 033.004-T docs) packaged into shipment 033-S and sequenced before 010-S.
