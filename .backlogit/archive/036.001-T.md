Harden `extractRecapAudioJS` in `internal/browser/recap.go` for early-mount SharePoint stream playback (`47D1E1C0` part 1a) and blocked non-blob direct candidate skipping (`47D1E1C0` part 1b).

## File Budget

* `internal/browser/recap.go`
* `internal/browser/recap_test.go`

### Scope and Approach

1. **Skip direct non-blob `candidateUrl` fetches when `info.isDownloadBlocked && streamSurface`** (`internal/browser/recap.go:357-373`): inside `for (const candidateUrl of candidates)`, keep `checkIdentityAgainst(candidateUrl, pageUrl, candState)`, the `enforceIdentity` check, and the pre-fetch `duration` limit loop (`media.duration`, `info.duration`, `info.durationSeconds`) intact first (preserving Protected Invariants 2 and 3), then immediately before `if (!fetchFn)` add `if (info.isDownloadBlocked && streamSurface && !/^blob:/i.test(candidateUrl)) { blockedErr = new Error('recap audio download is blocked by SharePoint permissions (isDownloadBlocked=true)'); lastFetchErr = blockedErr; continue; }` so non-`blob:` direct URLs never trigger wasted HTTP 403/HTML fetches on `streamembed.aspx`/`stream.aspx` while `blob:` candidates and `!streamSurface` pages preserve existing behavior.
2. **Periodic `1000ms` `'Play video'` re-clicking + replacement `<video>` mute/play safety** (`internal/browser/recap.go:1658-1692`): replace `let btnClicked = false; let mediaPlayTriggered = false;` in `captureStreamEmbedAudio()` with `let lastBtnClickAt = 0; let triggeredMediaEl = null;`. In `triggerPlaybackIfReady()`, return early if `pathAActive`; whenever `m && !pathAActive`, enforce `m.muted = true; m.volume = 0; if (m.playbackRate !== 16) m.playbackRate = 16;`; click `btn` whenever `!activityObserved && btn && typeof btn.click === 'function' && (lastBtnClickAt === 0 || Date.now() - lastBtnClickAt >= 1000)` setting `lastBtnClickAt = Math.max(1, Date.now())`; and trigger `m.play()` once per `<video>` element (`m !== triggeredMediaEl && !pathAActive`). In the `while (Date.now() < deadlineAt)` loop, invoke `triggerPlaybackIfReady()` whenever `!pathAActive && (!activityObserved || !triggeredMediaEl || (playerDoc.querySelector && playerDoc.querySelector('audio, video') !== triggeredMediaEl))`.
3. **Unit tests (`internal/browser/recap_test.go`)**: add `TestWave2ARecapAudioEarlyMountPlayAndBlockedSkip` covering (a) delayed player initialization + replacement `<video>` mounting where clicks at `t=0` and `t=1000ms` occur before readiness and `t=2000ms` starts playback and stops clicking once `activityObserved` is `true`, and (b) `info.isDownloadBlocked && streamSurface` skipping non-blob `fetch` calls while still rejecting conflicting candidate identities. Never clamp `setTimeout` delays with `ms >= 10000` (`fetchBytesOnce`'s 15s `reqTimer`), coordinate mocked `Date.now()` monotonically with `1000ms` intervals, and attach a `process.on('beforeExit')` completion sentinel.

## Acceptance Criteria

* `extractRecapAudioJS` skips invoking `fetch` on non-`blob:` `candidateUrl` entries when `info.isDownloadBlocked && streamSurface` is true (after running `checkIdentityAgainst`, `enforceIdentity`, and duration-cap checks), while preserving `!streamSurface` direct probes (`TestRecapJSVroomItemIdLowercaseAndIsDownloadBlocked`).
* `triggerPlaybackIfReady()` re-clicks the `'Play video'` button every `>= 1000ms` while `!activityObserved && !pathAActive`, stops clicking immediately once `activityObserved` or `pathAActive` becomes `true`, and enforces `muted = true`, `volume = 0`, `playbackRate = 16`, and one-shot `.play()` per `<video>` element (`triggeredMediaEl`).
* `go test -race "-run=TestWave2ARecapAudioEarlyMountPlayAndBlockedSkip|TestRecapJSVroomItemIdLowercaseAndIsDownloadBlocked" ./internal/browser/...`, `go vet ./...`, and `golangci-lint run` exit `0`.
