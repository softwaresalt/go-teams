<!-- BEGIN:description -->
Contract CLI consumers `isAISummaryDisabled`, `effectiveAISummaryDelay`, and `runAppendAISummary` in `internal/cli/capture.go` so `ai_summary_delay: "0s"` in `config.yaml` (or `--ai-summary-delay 0s`) never disables AI Summary capture in `past-recap` or `auto` modes, while `Config.NoAISummary` (`--no-ai-summary`) and `ephemeral-live` suppress both Recap and post-call AI Summaries (`47D1E1C0` part 3, contract step).

## File Budget

* `internal/cli/capture.go`
* `internal/cli/capture_test.go`

### Scope and Approach

1. **Contract `isAISummaryDisabled(c config.Config) bool` (`internal/cli/capture.go:73-86`)**:
   * Return `false` when `strings.TrimSpace(c.AppendAISummary) != ""`.
   * Return `true` when `c.NoAISummary` is `true` OR `strings.EqualFold(strings.TrimSpace(c.CaptureMode), config.CaptureModeEphemeralLive)`.
   * Return `false` otherwise (removing the `c.AISummaryDelay` `d == 0` check so `ai_summary_delay: "0s"` in `config.yaml` or `--ai-summary-delay 0s` keeps `isAISummaryDisabled == false` across `past-recap`, `auto`, and `live-with-summary`).
2. **Enforce `cfg.NoAISummary` in `effectiveAISummaryDelay(cfg config.Config, isRecap bool)` (`internal/cli/capture.go:88-107`)**: return `0` immediately when `isRecap || cfg.NoAISummary` so `Config.NoAISummary` unconditionally suppresses post-live-call timers and deferred queue entries even when `AISummaryDelay` is `""` or positive.
3. **Clear `recapCfg.NoAISummary = false` in `runAppendAISummary` (`internal/cli/capture.go:112-120`)** alongside `recapCfg.AISummaryDelay = ""`.
4. **Unit tests (`internal/cli/capture_test.go`, grouped via `t.Run`)**: update `TestDefaultNewMeetingAndNewSessionWireAISummaryFlags` (asserting `AISummaryDelay: "0s"` without `NoAISummary` keeps `DisableAISummary == false`, while `NoAISummary: true` sets `DisableAISummary == true`) and add subtests verifying `isAISummaryDisabled`, `effectiveAISummaryDelay` (including `NoAISummary: true` with `AISummaryDelay: ""` and `"15m"`), and end-to-end `runCmd` invocations across `past-recap`, `auto`, `live-with-summary`, `ephemeral-live`, and `--append-ai-summary`.
<!-- END:description -->

## Acceptance Criteria

* `isAISummaryDisabled(c)` returns `false` when `AppendAISummary != ""`, `true` ONLY when `c.NoAISummary` or `CaptureMode == "ephemeral-live"`, and `false` for `past-recap`, `auto`, and `live-with-summary` even when `AISummaryDelay == "0s"`.
* `effectiveAISummaryDelay(cfg, isRecap)` returns `0` whenever `isRecap || cfg.NoAISummary`, and `runAppendAISummary` clears `recapCfg.NoAISummary = false`.
* `go test -race ./internal/cli/...`, `go vet ./...`, and `golangci-lint run` exit `0`.
