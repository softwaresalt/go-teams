# Compound Learnings

Institutional knowledge captured by the `compound` skill: solved problems, root causes, resolutions, and prevention notes. Organized by category subdirectory (e.g. `build-errors/`, `test-failures/`, `runtime-errors/`, `concurrency-issues/`, `security-issues/`, `best-practices/`, `workflow-issues/`).

Maintained over time by the `compound-refresh` skill, which keeps entries accurate, deduplicated, and evidence-backed as the codebase evolves.
