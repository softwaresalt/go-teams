<!-- BEGIN:acceptance-criteria -->
1. internal/updater uses only the Go standard library and internal/version (zero new external dependencies in go.mod).
2. Updater.swap acquires <exe>.lock before removing stale <exe>.old and releases <exe>.lock only after renaming/rolling back <exe> and removing <exe>.old, serializing concurrent updates so one process cannot delete another process's <exe>.old rollback copy.
3. When <exe>.lock is held by an active non-stale owner past lockWaitTimeout, Update fails closed with ErrUpdateLocked, leaves <exe> and the holder's <exe>.lock untouched, and removes its own temporary download file.
4. When <exe>.lock is older than lockStaleAfter (both valid JSON metadata and empty/unreadable crash lockfiles whose ModTime exceeds lockStaleAfter), lockSwap evicts the stale lock via atomic rename-then-remove and acquires a fresh lock; token-verified release never deletes a lock owned by a newer token.
5. go test -race ./internal/updater/... passes with TestUpdateConcurrentSwapsDoNotDeleteRollbackCopy, TestUpdateFailsWhenLockHeld, TestUpdateEvictsStaleLock, and TestSwapLockReleaseDoesNotDeleteNewerOwnerLock.
<!-- END:acceptance-criteria -->
