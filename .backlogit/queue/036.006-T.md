<!-- BEGIN:description -->
Migrate capture and `--queue` flag producers in `internal/cli/join.go` to populate and forward `Config.NoAISummary` (`47D1E1C0` part 3, producer migration step 1).

## File Budget

* `internal/cli/join.go`
* `internal/cli/join_test.go`

### Scope and Approach

1. **Populate `cfg.NoAISummary` in `applyCaptureFlags` (`internal/cli/join.go:220-222`)**: if `cmd != nil && cmd.Flags().Changed("no-ai-summary")`, set `cfg.NoAISummary = f.noAISummary` (and `if f.noAISummary { cfg.AISummaryDelay = "0s" }`); else if `f.noAISummary`, set `cfg.NoAISummary = true` and `cfg.AISummaryDelay = "0s"` (retaining `AISummaryDelay = "0s"` for interim compatibility until `036.008-T` contracts `capture.go`).
2. **Forward `--no-ai-summary` / `--no-ai-summary=false` in `inheritedQueueFlags` (`internal/cli/join.go:324-326`)**: when `cmd != nil && cmd.Flags().Changed("no-ai-summary")`, append `"--no-ai-summary"` if `f.noAISummary` and `"--no-ai-summary=false"` otherwise so per-line queue overrides propagate deterministically.
3. **Align CLI help text (`internal/cli/join.go:37,132`)**: update `captureTimingHelp` and `bindCaptureFlags` `--no-ai-summary` description to state that `--no-ai-summary` disables AI Summary capture for both Meeting Recaps and delayed post-call enrichment (removing `(same as --ai-summary-delay=0s)` while preserving `"--no-ai-summary"` for `help_test.go`).
4. **Unit tests (`internal/cli/join_test.go`)**: add `TestCaptureFlagsAndQueueForwardNoAISummary` verifying `Config.NoAISummary` population across `--no-ai-summary`, `--no-ai-summary=false`, `--ai-summary-delay 0s` (`NoAISummary == false`), and `inheritedQueueFlags` / `--queue` per-line overrides.
<!-- END:description -->

* `inheritedQueueFlags` forwards both `--no-ai-summary` and `--no-ai-summary=false` when changed, and `captureTimingHelp` / `bindCaptureFlags` accurately describe `--no-ai-summary`.
* `go test -race "-run=TestCaptureFlagsAndQueueForwardNoAISummary|TestAllSubcommandsProvideComprehensiveHelpAndExamples" ./internal/cli/...`, `go vet ./...`, and `golangci-lint run` exit `0`.
