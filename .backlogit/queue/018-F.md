<!-- BEGIN:description -->
Add an executable-keyed inter-process lock (<exe>.lock and exclusive control lock <exe>.lock.ctl via os.OpenFile O_CREATE|O_EXCL|O_WRONLY, 0o600) with JSON owner metadata (pid, random token, created_at), bounded context-aware wait polling (returning ErrUpdateLocked on timeout), dead-holder liveness proof via injectable isProcessAlive(pid) before stale eviction after lockStaleAfter (failing closed when holder PID is alive, <= 0, or metadata is unreadable/corrupt), and <exe>.lock.ctl-synchronized stale replacement and authoritative token-verified release around Updater.swap in internal/updater so two concurrent teams-cli update processes cannot delete each other's <exe>.old rollback copy. Source stash: 2D0BAA19 (shipment 016-S, feature 016-F, task 016.002-T, PR #40, review thread PRRT_kwDOTStvas62SjnB); deliberation: 007-DL (docs/decisions/2026-11-11-update-interprocess-lock-deliberation.md); plan: docs/plans/2026-11-11-update-interprocess-lock-plan.md.
<!-- END:description -->
