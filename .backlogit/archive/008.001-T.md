title: Escape participant-controlled fields in the transcript writer

internal/transcript: Writer.WriteEvent interpolates Teams-controlled Speaker/Text directly into Markdown, so a crafted display name or caption can inject Markdown/HTML (headings, links, emphasis, code, tables) or break line structure via newlines. Add a sanitizer that (1) replaces CR/LF/control chars with a single space and (2) backslash-escapes Markdown-structural runes (backtick, *, _, [, ], <, >, #, |, backslash) in Speaker and Text before formatting. Table-driven tests for injection vectors (leading #, [x](url), <script>, **, embedded newline) and that ordinary text/punctuation is preserved readable. Scope: writer.go + writer_test.go.
