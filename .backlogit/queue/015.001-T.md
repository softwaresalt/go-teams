Implement post-meeting Recap audio extraction and MP3 encoding in `internal/browser/recap.go` and `internal/browser/meeting_chrome.go` (Size: S | Complexity: medium, domain: code, posture: test-first, files: `internal/browser/recap.go`, `internal/browser/meeting_chrome.go`).

Scope and approach:
1. In `internal/browser/recap.go`, add `extractRecapAudioJS` and `captureRecapAudioFromTargets(ctx context.Context, port int, ownerPageID string, w io.Writer) error` that queries `listCDPTargets(port)`, resolves `ownedFrames` via `fetchOwnedFrames`, filters targets strictly through `isTargetInCaptureScope(t, ownerPageID, ownedFrames)`, evaluates `extractRecapAudioJS` to obtain 44.1 kHz mono `int16` base64 PCM chunks (from `[data-recap-audio-pcm]`, `window.g_fileInfo.audioPcmBase64`, or `<audio>`/`<video>`/`g_fileInfo` media sources decoded via Web Audio `AudioContext`/`OfflineAudioContext`), decodes each chunk with `decodeAudioPayload`, and encodes to MP3 via `audio.NewEncoder(w, audio.SampleRate)` (`WritePCM` + `Flush()`).
2. In `internal/browser/meeting_chrome.go`, persist `m.cdpPort = port` in `joinHeaded` after `launchCleanHeadedBrowser` succeeds, and update `(*chromeMeeting).CaptureAudio(ctx context.Context, w io.Writer)` to branch on `if m.IsRecap()` and invoke `m.captureRecapAudio(ctx, w)` so Recap audio capture completes finitely.

Acceptance criteria:
1. `captureRecapAudioFromTargets` inspects only CDP targets passing `isTargetInCaptureScope(t, ownerPageID, ownedFrames)` and encodes mono 44.1 kHz `int16` PCM through `audio.NewEncoder(w, audio.SampleRate)` (`WritePCM` + `Flush()`).
2. `joinHeaded` stores `m.cdpPort = port` so post-`Join` `CaptureAudio` has the active DevTools port in both headed and headless modes.
3. `(*chromeMeeting).CaptureAudio` in Recap mode (`m.IsRecap() == true`) writes valid MP3 frames to `w` and returns `nil` finitely without blocking for `ctx.Done()`, or returns a descriptive error when no Recap audio source is available.
4. `go build ./...` and `go vet ./...` pass cleanly. Source stash: DF1F461F.
