<!-- BEGIN:description -->
Migrate `schedule` flag and per-meeting entry producers in `internal/cli/schedule.go` to populate `Config.NoAISummary`, enforce positive per-meeting `ai_summary_delay` precedence, and align `--no-ai-summary` flag help (`47D1E1C0` part 3, producer migration step 2).

## File Budget

* `internal/cli/schedule.go`
* `internal/cli/schedule_test.go`

### Scope and Approach

1. **Align `bindScheduleFlags` description (`internal/cli/schedule.go:54`)**: update `--no-ai-summary` description to `"disable AI Summary capture for both Meeting Recaps and post-call enrichment"` (matching `join.go:132`).
2. **Populate `cfg.NoAISummary` in `applyScheduleFlags` (`internal/cli/schedule.go:88-90`)**: if `cmd != nil && cmd.Flags().Changed("no-ai-summary")`, set `cfg.NoAISummary = f.noAISummary` (and `if f.noAISummary { cfg.AISummaryDelay = "0s" }`); else if `f.noAISummary`, set `cfg.NoAISummary = true` and `cfg.AISummaryDelay = "0s"`.
3. **Preserve 3-tier `schedule` override in `buildScheduleEntryConfig` (`internal/cli/schedule.go:128-130`)**: when `e.AISummaryDelay != nil`, set `entryCfg.AISummaryDelay = (*e.AISummaryDelay).String()`, and when `*e.AISummaryDelay > 0`, set `entryCfg.NoAISummary = false` so a positive per-meeting `ai_summary_delay` overrides a global `schedule --no-ai-summary` flag while a per-meeting `mode: past-recap` + `ai_summary_delay: 0s` without `--no-ai-summary` keeps `NoAISummary == false`.
4. **Unit tests (`internal/cli/schedule_test.go`)**: add `TestScheduleNoAISummaryAndPerMeetingDelayPrecedence` verifying `NoAISummary` state across global `schedule --no-ai-summary`, positive per-meeting `ai_summary_delay` override (`NoAISummary == false`), and per-meeting `mode: past-recap` + `ai_summary_delay: 0s` without `--no-ai-summary` (`NoAISummary == false`).
