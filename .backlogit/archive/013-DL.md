# Templated YAML Config Generator Subcommand and User Documentation Restructure (024-S)

## Problem Frame

<!-- BEGIN:problem-frame -->
Two medium-priority feature stash entries (D4D4F773 and AB5E856D) address user onboarding and configuration legibility for non-technical users and legitimate AI agentic workflows: (1) D4D4F773 adds a dedicated CLI subcommand (teams-cli generate-config, aliases init-config and gen-config) backed by internal/config/template.go (TemplateYAML, ResolveTemplatePath, WriteTemplate) to emit a fully commented YAML configuration file with inline plain-language explanations and commented-out example values, supporting --output-dir/-d, --name/-n, --force, and positional target arguments with path-traversal protection (ErrInvalidConfigName) and exclusive creation (ErrConfigExists); (2) AB5E856D restructures README.md into a concise, welcoming cover page stating the legitimate AI agentic context-capture purpose of teams-cli, extracts and expands comprehensive step-by-step non-technical setup and CLI/config reference documentation into docs/USER_GUIDE.md, and synchronizes config.example.yaml, docs/ARCHITECTURE.md, and docs/QUALITY_SCORE.md.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
* Option A: Minimal CLI flag on root command (--init-config) dumping raw yaml.Marshal(DefaultConfig()) and keeping all documentation in a single monolithic README.md (rejected: yaml.Marshal strips explanatory comments and omits optional fields/aliases, and a monolithic README overwhelms non-technical users). * Option B (chosen): Dedicated teams-cli generate-config subcommand (internal/cli/generate_config.go) backed by internal/config/template.go (TemplateYAML, ResolveTemplatePath, WriteTemplate with 0o700/0o600 permissions, ErrInvalidConfigName, and ErrConfigExists) paired with a concise cover-page README.md, comprehensive docs/USER_GUIDE.md, and synchronized config.example.yaml, docs/ARCHITECTURE.md, and docs/QUALITY_SCORE.md across 3 width-isolated tasks (024.001-T..024.003-T) under feature 024-F and shipment 024-S.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option B (3 width-isolated tasks 024.001-T..024.003-T under feature 024-F and shipment 024-S, sequenced after 023-S): (1) 024.001-T implements TemplateYAML(), ResolveTemplatePath(), WriteTemplate(), ErrConfigExists, and ErrInvalidConfigName in internal/config/template.go with unit tests in internal/config/template_test.go; (2) 024.002-T implements newGenerateConfigCommand in internal/cli/generate_config.go (--output-dir/-d, --name/-n, --force, positional argument support, aliases init-config and gen-config), wires it into internal/cli/root.go, and adds unit tests in internal/cli/generate_config_test.go; (3) 024.003-T restructures README.md as a concise cover page, creates docs/USER_GUIDE.md for non-technical users preserving 100% of the CLI/config technical reference, and updates config.example.yaml, docs/ARCHITECTURE.md, and docs/QUALITY_SCORE.md.
<!-- END:chosen-direction -->
