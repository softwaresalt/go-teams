Implement the pure-Go self-updater in `internal/updater/updater.go` and `internal/updater/updater_test.go` using only the Go standard library (Size: S | Complexity: medium, domain: code, posture: test-first, files: `internal/updater/updater.go`, `internal/updater/updater_test.go`).

Scope and approach:
1. In `internal/updater/updater.go`, implement `Config`, `Updater`, `Result`, `AssetName(goos, goarch string) string`, `Check(ctx context.Context, targetVersion string) (Result, error)`, and `Update(ctx context.Context, targetVersion string, force bool) (Result, error)`:
   - Queries `/repos/<repo>/releases/latest` (or `/repos/<repo>/releases/tags/v<normalized>` when `targetVersion != ""`) with configurable `HTTPClient`, `APIBaseURL`, `Repo`, `CurrentVersion`, `GOOS`, `GOARCH`, and `ExecutablePath`.
   - Enforces `https://` on all API and asset download URLs except loopback hosts (`127.0.0.1`, `localhost`, `::1`).
   - Bounds response bodies via `io.LimitReader`, downloads and parses `SHA256SUMS` to locate the expected SHA-256 hex digest for `teams-cli-<goos>-<goarch>[.exe]`, streams the binary asset to a temporary file in `filepath.Dir(ExecutablePath)` while computing `sha256.New()`, and fails closed (`ErrChecksumMismatch`, removing the temp file) if the digest mismatches.
   - Performs Windows-safe atomic replacement (`os.Remove(oldPath)` -> `os.Rename(exePath, oldPath)` -> `os.Rename(tmpPath, exePath)` with rollback `os.Rename(oldPath, exePath)` if the second rename fails, followed by best-effort `os.Remove(oldPath)`).
2. In `internal/updater/updater_test.go`, add `httptest.NewServer` unit tests covering `Check`, `Update` when up to date vs. newer release available, verified binary swap, SHA-256 mismatch rejection leaving the original executable untouched, and non-HTTPS non-loopback URL rejection.

Acceptance criteria:
1. `internal/updater` uses only the Go standard library and `internal/version` (zero new external dependencies in `go.mod`).
2. `Update` verifies the binary's SHA-256 digest against `SHA256SUMS` before touching `ExecutablePath` and rolls back from `<exe>.old` if the final rename fails.
3. All unit tests in `internal/updater/updater_test.go` pass under `go test -race ./internal/updater/...`. Source stash: A08726BC.
