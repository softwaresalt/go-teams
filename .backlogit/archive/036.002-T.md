### Scope and Approach

1. **Shared pre-allocation cap state (`internal/browser/recap.go:653,773,986`)**: declare `let inFlightSourceBytes = 0;` alongside `let streamSourceBytes = 0;` in `captureStreamEmbedAudio()`. Check `streamSourceBytes + inFlightSourceBytes + u8.byteLength > maxRecapAudioSourceBytes` in `recordMSESegment` (`recap.go:778,805`), and reset `inFlightSourceBytes = 0;` alongside `streamSourceBytes = mseBytesTotal();` in `maybeStartPathA().catch` (`recap.go:986`). (Inline the sum comparison directly rather than adding a separate helper function so total edited functions stays `<= 4`.)
2. **Per-worker `inFlightSourceBytes` reservation and synchronous abort in `fetchBytesOnce` (`internal/browser/recap.go:1003-1135`)**:
   * Track `let workerReserved = 0;` inside `fetchBytesOnce` with unconditional `finally` cleanup `if (workerReserved > 0) { inFlightSourceBytes = Math.max(0, inFlightSourceBytes - workerReserved); workerReserved = 0; }`.
   * When `Content-Length` `cl` is finite and `> 0`, check `streamSourceBytes + inFlightSourceBytes + cl > maxRecapAudioSourceBytes` (setting `fatalErr = new Error(limitError); if (abortCtrl) abortCtrl.abort(); throw fatalErr;`), then reserve `inFlightSourceBytes += cl; workerReserved += cl;`.
   * On `!resp.body || !resp.body.getReader`, compute `const extra = Math.max(0, u8.byteLength - workerReserved);`, check `streamSourceBytes + inFlightSourceBytes + extra > maxRecapAudioSourceBytes`, release `workerReserved` (`inFlightSourceBytes = Math.max(0, inFlightSourceBytes - workerReserved); workerReserved = 0;`), and commit `streamSourceBytes += u8.byteLength`.
   * On streaming `resp.body.getReader()`, before pushing each chunk `v`, compute `const extra = Math.max(0, (total + v.byteLength) - workerReserved);`; if `extra > 0` and `streamSourceBytes + inFlightSourceBytes + extra > maxRecapAudioSourceBytes`, **set `fatalErr = new Error(limitError)` and call `if (abortCtrl) abortCtrl.abort()` synchronously FIRST**, and only then `try { await reader.cancel(); } catch (_) {}` before `throw fatalErr` (closing any microtask yield window). Otherwise reserve `inFlightSourceBytes += extra; workerReserved += extra;`. On `part.done`, release `workerReserved`, verify `streamSourceBytes + inFlightSourceBytes + total <= maxRecapAudioSourceBytes`, and commit `streamSourceBytes += total`.
3. **Unit tests (`internal/browser/recap_test.go`)**: add `TestWave2APathAInFlightByteReservation` covering (a) concurrent Path A streaming workers without `Content-Length` failing closed synchronously with `limitError` when aggregate `streamSourceBytes + inFlightSourceBytes` exceeds `maxRecapAudioSourceBytes` before any worker finishes, and (b) retryable HTTP `408`/`503` and mid-stream failures releasing `workerReserved` across 5-attempt retries without false cap exhaustion. Never clamp `setTimeout` delays `ms >= 10000` and attach `process.on('beforeExit')`.
