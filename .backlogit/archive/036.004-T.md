Normalize case-insensitive single-pass `fileUrl`/`id` percent-decoding (`69AB7ACC` / `F-4b`), tighten `copyAISummaryJS` fresh `.fai-CopilotMessage` container guards (`196AB9E4` / `F-1b`), and add `canonicalStreamTargetMatch` / `recapItemID` characterization coverage (`0DE2E900`, `39450846` `U5-R3`).

## File Budget

### Scope and Approach

1. **Case-insensitive query keys and single-pass scheme-less/server-relative `fileUrl` & `id` decoding (`internal/browser/recap.go:90-124,2342-2381`)**:
   * Define scheme-less non-protocol-relative path predicate: a trimmed value `v` that does not start with `//` or `:` and has no case-insensitive `^[A-Za-z][A-Za-z0-9+.-]*:` scheme prefix (covering both `/personal/.../100% Sync.mp4?web=1` and `Recordings/foo%20bar.mp4?web=1`).
   * In Go `applyQueryIdentity` (`recap.go:2342-2381`): look up `threadId`, `driveItemId`, `driveId`, `callId`, `iCalUid`, `fileUrl`, and `id` case-insensitively and deterministically across `vals` (reusing `singleCaseInsensitiveQueryValue` from `meeting_chrome.go:440` or rejecting ambiguous conflicting case-variant values); for `"fileUrl"` and `"id"`, when `v` matches the scheme-less non-`//` predicate, strip any `?` query suffix (`if qIdx := strings.IndexByte(v, '?'); qIdx >= 0 { p = v[:qIdx] } else { p = v }`) without calling `url.Parse`; otherwise — keeping protocol-relative URLs (`strings.HasPrefix(v, "//")`, e.g., `//example.invalid/Recordings/Sync.mp4`) in the `url.Parse` branch alongside scheme-bearing `http://` / `https://` URLs — parse via `if fu, err := url.Parse(v); err == nil { p = fu.Path }` in parity with JS `checkIdentityAgainst`; reject trailing `/` (`!strings.HasSuffix(p, "/")`), and extract `path.Base(p)` preserving literal `%` and `#` on scheme-less paths and single-pass `%`-decoding on scheme-bearing and protocol-relative URLs.
   * In JS `checkIdentityAgainst` (`recap.go:90-124`): iterate `params.entries()` matching keys case-insensitively (`keyLower === ...`); hoist `const rawVal = String(value || '').trim(); if (!rawVal) continue;` before the `paramKey === 'id'` media-extension regex check; when `rawVal` has no `/^[a-z][a-z0-9+.-]*:/i` scheme prefix and does not start with `//` or `:`, set `alreadyDecoded = true` and strip any `?` query suffix (`const qIdx = rawVal.indexOf('?'); filePath = qIdx >= 0 ? rawVal.slice(0, qIdx) : rawVal;`), reserving `new URL(rawVal, baseUrl).pathname` + `safeDecodeURIComponent` strictly for scheme-bearing (`http://` / `https://`) and protocol-relative (`//...`) URLs (still throwing `'recap audio recording identity mismatch'` when `paramKey === 'fileUrl'` fails to parse).
2. **Tighten `copyAISummaryJS` Copilot container and prompt exclusions (`internal/browser/recap.go:2531-2556`)**:
   * Exclude elements inside transcript containers (`!(el && el.closest && el.closest('.ms-List, [data-tid*="transcript" i]'))`) when locating `recapBtn`.
   * In `freshCopyBtns`, require `Boolean(msg) && !(msg.dataset && msg.dataset.goTeamsPreexisting === 'true') && !(btn && btn.closest && btn.closest('.fui-ChatMyMessage, .fui-ChatMyMessage__body, [class*="ChatMyMessage"]'))`.
3. **Unit & characterization tests (`internal/browser/recap_test.go`, grouped via `t.Run`)**:
   * **Expected-RED roster (`TestWave2AIdentitySinglePassAndCopilotGuard`, targeting `recap.go` only)**: (a) Go `ExtractMeetingIdentity` and JS `checkIdentityAgainst` parity table covering case-variant (`?ID=`, `?FILEURL=`, `?DriveItemId=`), leading-slash (`/Recordings/foo%20bar.mp4`), and relative (`Recordings/100% Sync.mp4?web=1`) paths containing literal `%20`, literal `% `, literal `#`, trailing whitespace, and trailing `/` rejection, plus scheme-bearing (`https://...`) and protocol-relative (`//example.invalid/Recordings/Sync.mp4`, `//example.invalid/Recordings/foo%20bar.mp4?web=1`) `fileUrl` / `id` single-layer `%`-decoding; (b) `copyAISummaryJS` ignoring uncontained Copy buttons (`closest('.fai-CopilotMessage') === null`), `.fui-ChatMyMessage` user bubbles, `.ms-List` transcript rows, and pre-existing `.fai-CopilotMessage` items until a new post-click `.fai-CopilotMessage` renders (leaving `setTimeout` `ms >= 10000` unclamped and attaching `process.on('beforeExit')`).
   * **Green characterization subtest (outside the expected-RED roster so `meeting_chrome.go` is never stubbed)**: direct table-driven assertions on `canonicalStreamTargetMatch` (`0DE2E900`) covering uppercase `ID`, lowercase `uniqueId`, mixed-case `DriveId`/`DRIVEID`, ambiguous duplicate case-variant keys (`?uniqueId=a&UniqueId=b`), and missing target parameters, alongside `U5-R3` `recapItemID` verification.
