<!-- BEGIN:description -->
Harden `captureRecapAudioFromTargets` in `internal/browser/recap.go` for path-based SharePoint stream target detection, attempt-0 `isDownloadBlocked=true` retry, selective non-stream target skipping (`47D1E1C0` part 2), and `xplatplugins.aspx`-independent delayed-mount discovery polling (`7883544E` `U2-R5`, `39450846` `U1-R3`, `U3-R3`, `U6-R3`).

## File Budget

* `internal/browser/recap.go`
* `internal/browser/recap_retry_test.go`

### Scope and Approach

1. **Configurable retry wait (`internal/browser/recap.go:2257,3637`)**: define package-level `var recapAudioRetryDelay = 1 * time.Second` alongside `recapAudioEvalTimeout` and use `time.NewTimer(recapAudioRetryDelay)` in `captureRecapAudioFromTargets`, preserving `<-ctx.Done()`, `<-captureCtx.Done()`, `timer.Stop()`, and `errors.Join(lastErr, captureCtx.Err())`.
2. **Path-based `isStreamTarget`, filtered `hasStreamEmbedTarget`, and `recapTargetRank` (`internal/browser/recap.go:2010-2040`)**:
   * Define `isStreamTarget(rawURL string) bool` by parsing `u, err := url.Parse(strings.TrimSpace(rawURL))`, returning `false` when `err != nil || isAuthRedirectURL(rawURL)`, and checking `lowerPath := strings.ToLower(u.Path)` for `strings.Contains(lowerPath, "streamembed.aspx") || strings.Contains(lowerPath, "stream.aspx")` (ignoring query/fragment strings).
   * Compute `hasStreamEmbedTarget` strictly over targets `t` satisfying `isTargetInCaptureScope(t, ownerID, frames) && !isAuthRedirectURL(t.URL) && !hasMeetingIdentityConflict(expected, ExtractMeetingIdentity(t.URL)) && isStreamTarget(t.URL)` (removing unused `hasXplatTarget`).
   * Update `recapTargetRank` so `t.Type == "iframe" && isStreamTarget(t.URL)` is rank `0`, `t.Type == "page" && isStreamTarget(t.URL)` is rank `1`, `t.Type == "iframe" && strings.Contains(strings.ToLower(t.URL), "xplatplugins.aspx")` is rank `2`, other `iframe` is rank `3`, and non-stream `page` is rank `4`.
3. **Selective `skipNonStreamTargets` and `sawRetryableStreamTargetErr` retry reconciliation (`internal/browser/recap.go:2038-2256`)**:
   * Track per-attempt `skipNonStreamTargets := false` and `sawRetryableStreamTargetErr := false`.
   * Separate `!isTargetInCaptureScope(target, ownerID, frames)` (`continue`) from `hasMeetingIdentityConflict(expected, ExtractMeetingIdentity(target.URL))`: on a conflicting owned URL, call `setLastErr(fmt.Errorf("browser: recap audio frame URL does not match requested recording"))` (priority `0` so an evaluated valid stream target's priority-`1` `isDownloadBlocked=true` still outranks a skipped sibling frame URL, while single-frame URL mismatches still set `lastErr != nil` and fail fast on attempt `0`) and `continue`.
   * Guard non-stream targets via `if skipNonStreamTargets && !isStreamTarget(target.URL) { continue }` so `xplatplugins.aspx` and outer `/v2/` targets are skipped after a stream failure while remaining non-conflicting `streamembed.aspx`/`stream.aspx` targets still run on `identity mismatch`/`unverified`/`-32000`.
   * When `isStreamDeadlineMsg(msg) || (isStreamTarget(target.URL) && strings.Contains(msg, "isDownloadBlocked=true"))` on `evalErr != nil` or `payload.Error != ""`, set `skipNonStreamTargets = true`, and if `attempt == 0`, set `sawRetryableStreamTargetErr = true`.
   * Set `isDownloadBlockedErr := lastErr != nil && strings.Contains(lastErr.Error(), "isDownloadBlocked=true")` and `shouldRetry := attempt < maxAttempts-1 && (sawRetryableStreamTargetErr || (!hasStreamEmbedTarget && (lastErr == nil || isDownloadBlockedErr)))`.
4. **Unit tests (`internal/browser/recap_retry_test.go`, non-parallel with `t.Cleanup`)**:
   * In `TestCaptureRecapAudioReturnsErrorWhenNoAudioAvailable` (`recap_retry_test.go:788`), override `recapAudioRetryDelay = 5 * time.Millisecond` (restoring via `t.Cleanup`, no `t.Parallel()`) and assert `strings.Contains(err.Error(), "unavailable for requested recording")`.
   * Add `TestWave2ACaptureRecapAudioRetryBreakAndDiscovery` (no `t.Parallel()`, restoring `recapAudioRetryDelay` via `t.Cleanup`) covering (a) attempt-0 `isDownloadBlocked=true` retry on mounted stream targets (`parentEvals == 0`, stopping after attempt `1` on persistent block, and evaluating a second stream target when a first bare stream iframe returned `identity unverified`), (b) `xplatplugins.aspx`-independent delayed-mount discovery when `lastErr == nil` (including `?fileUrl=.../stream.aspx` and SSO `?redirect_uri=.../streamembed.aspx` query strings), and (c) `errPriority` preservation of stream-deadline errors over `isDownloadBlocked=true` across attempts (`U6-R3`).

## Acceptance Criteria

* `captureRecapAudioFromTargets` retries once on `attempt == 0` when a mounted `streamembed.aspx` or `stream.aspx` target returns `isDownloadBlocked=true` (stopping after attempt `1` if persistent), skips `xplatplugins.aspx` and outer `/v2/` targets in the same attempt on retryable stream errors while preserving sibling stream target evaluation on identity errors, and polls delayed mounts up to `maxAttempts` (`8`) without requiring `hasXplatTarget`.
* `isStreamTarget` inspects parsed `u.Path` (excluding `isAuthRedirectURL` and query/fragment strings), `errPriority` preserves stream-deadline errors (`priority 2`) above `isDownloadBlocked=true` (`priority 1`), and `TestCaptureRecapAudioReturnsErrorWhenNoAudioAvailable` completes all 8 attempts cleanly in milliseconds.
* `go test -race "-run=TestWave2ACaptureRecapAudioRetryBreakAndDiscovery|TestCaptureRecapAudioReturnsErrorWhenNoAudioAvailable|TestRecapRound4ReviewFixes|TestCaptureRecapAudio" ./internal/browser/...`, `go vet ./...`, and `golangci-lint run` exit `0`.
