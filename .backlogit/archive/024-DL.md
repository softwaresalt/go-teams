# Recap audio cold SharePoint transcode resilience and %APPDATA% profile fallback (035-S)

## Problem Frame

<!-- BEGIN:problem-frame -->
When running go-teams --queue against a cold 60.6-minute (3637.76s, 605-segment) Teams Meeting Recap and when an operator authenticated under %APPDATA%\go-teams\profile (or %APPDATA%\teams-cli\profile) runs CLI/queue commands without --profile-dir, two failures occur: (1) resolveExpandedProfileDir checks only %LOCALAPPDATA%\go-teams\profile and %LOCALAPPDATA%\teams-cli\profile, missing persisted Teams sessions in %APPDATA% / os.UserConfigDir() and returning ErrAccountRequired; (2) cold SharePoint oneDrive.transcode audio segments on 60+ minute recordings exceed the 120s Path A capture deadline (8 workers, 3 attempts) and fall into Path B's 'recap audio MSE stream incomplete before deadline' check because 1-2 initial mseSegments (~12s) were appended before Path A paused <video>, triggerPlaybackIfReady sets a single playTriggered boolean when clicking Play video before <video> mounts, and captureRecapAudioFromTargets does not retry streamembed/stream deadline failures.
<!-- END:problem-frame -->

## Options

<!-- BEGIN:options -->
Option A (Recommended): Scale production captureStreamEmbedAudio deadlineAt to 240000ms (maxRecapAudioDurationSec > 300), increase Path A workers to 12 and fetchBytesWithCap retries to 5 attempts (250/500/1000/2000ms backoff including HTTP 408/429/5xx), split triggerPlaybackIfReady into btnClicked and mediaPlayTriggered, check in-flight pathAPromise before Path B MSE fallback, increase recapAudioEvalTimeout to 10m and retry once on attempt 0 stream deadline failures in captureRecapAudioFromTargets, and add %APPDATA% / os.UserConfigDir() sibling fallback in resolveExpandedProfileDir. Option B: Rely solely on Path B 16x MSE playback for long recordings. Option C: Change config.DefaultConfig() defaultProfileDir from %LOCALAPPDATA% to %APPDATA%.
<!-- END:options -->

## Chosen Direction

<!-- BEGIN:chosen-direction -->
Option A: Implement in-page and CDP cold-transcode resilience (4m production deadline, 12 workers, 5-attempt backoff with HTTP 408/429/5xx, separate btnClicked/mediaPlayTriggered tracking, in-flight Path A deadline error precedence, 10m recapAudioEvalTimeout, and 1 retry on attempt 0 deadline failure) plus non-breaking %APPDATA% / os.UserConfigDir() fallback in resolveExpandedProfileDir under covering feature 035-F and shipment 035-S (035.001-T..035.003-T).
<!-- END:chosen-direction -->
